#🌳 트리 다이어그램 편집기

**트리 다이어그램 제작부터 빈칸 문제 만들기까지**

수업 자료나 시험 문제에 활용할 수 있는 트리 다이어그램을 쉽고 빠르게
만들기 위한 웹 기반 편집기입니다.\
별도의 프로그램 설치 없이 HTML 파일을 브라우저에서 열어 바로 사용할 수
있습니다.

## ✨ 주요 기능

-   **트리 자동 생성**\
    입력값을 계층 구조로 작성하면 트리 다이어그램을 자동으로 생성합니다.

-   **도형 직접 편집**\
    원과 사각형을 캔버스에 추가하고 위치와 크기를 자유롭게 조절할 수
    있습니다.

-   **노드 연결**\
    도형의 연결점을 드래그하여 원하는 노드끼리 직접 연결할 수 있습니다.

-   **자동 정렬 및 간격 조정**\
    트리를 자동으로 정렬하고 가로·세로 간격을 조절할 수 있습니다.

-   **다중 선택 및 크기 조절**\
    여러 도형을 한 번에 선택하여 이동하거나 크기를 함께 조절할 수
    있습니다.

-   **빈칸 문제 만들기**\
    원하는 노드를 빈칸으로 지정하고 문제 화면과 정답 화면을 전환할 수
    있습니다.

-   **빈칸 모양 설정**\
    빗금 처리, 내용 숨기기, 괄호 표시 방식 중 원하는 형태를 선택할 수
    있습니다.

-   **이미지 저장**\
    완성한 다이어그램을 SVG 또는 PNG 이미지로 저장할 수 있으며, 흰색
    또는 투명 배경을 선택할 수 있습니다.

-   **실행 취소 / 다시 실행**\
    `Ctrl + Z`, `Ctrl + Y`를 이용해 편집 작업을 되돌리거나 다시 실행할
    수 있습니다.

## 🖥️ 사용 방법

### 1. 트리 만들기

왼쪽의 **입력값으로 트리 만들기**에 다음과 같이 입력합니다.

``` text
50
- 30
  - 20
  - 40
- 70
  - 60
  - 80
```

**입력값으로 트리 만들기** 버튼을 누르면 트리가 자동으로 생성됩니다.

직접 만들고 싶다면 **삽입** 메뉴에서 원 또는 사각형을 캔버스로 끌어 놓아
사용할 수 있습니다.

### 2. 트리 편집하기

도형을 클릭하여 선택한 후 직접 이동하거나 크기를 조절할 수 있습니다.\
빈 공간을 드래그하면 여러 도형을 한 번에 선택할 수 있습니다.

**디자인** 메뉴에서는 다음 기능을 사용할 수 있습니다.

-   자동 정렬
-   가로·세로 간격 조정
-   글자 크기 조정
-   선택한 도형의 크기 조정

### 3. 빈칸 문제 만들기

**문제 만들기** 메뉴에서 원하는 도형을 선택한 뒤 **빈칸 지정**을
누릅니다.

빈칸 표시 방식은 다음 중 선택할 수 있습니다.

-   빗금 처리
-   내용 숨기기
-   `(　　)` 괄호

**문제 화면 / 정답 화면**을 전환하면서 결과를 바로 확인할 수 있습니다.

### 4. 이미지로 저장하기

**내보내기** 메뉴에서 저장 배경과 파일 형식을 선택합니다.

-   배경: 흰색 / 투명
-   형식: SVG / PNG

## ⌨️ 주요 조작

  조작               기능
  ------------------ -----------------------------
  도형 클릭          도형 선택
  도형 드래그        위치 이동
  빈 공간 드래그     여러 도형 선택
  선택 핸들 드래그   도형 크기 조절
  Ctrl/Cmd + 클릭    다중 선택
  Delete             선택 항목 삭제
  Ctrl/Cmd + Z       실행 취소
  Ctrl/Cmd + Y       다시 실행
  우클릭             값 수정·빈칸 지정·노드 삭제

## 🚀 실행 방법

이 프로젝트는 별도의 설치 과정이 필요하지 않습니다.

1.  저장소를 다운로드하거나 Clone합니다.
2.  HTML 파일을 실행합니다.
3.  Chrome, Edge 등 웹 브라우저에서 바로 사용할 수 있습니다.

GitHub Pages를 사용하면 웹사이트 형태로도 배포할 수 있습니다.
